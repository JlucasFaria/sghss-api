# Matriz de rastreabilidade

Liga cada requisito ao caso de uso que o origina, aos endpoints que o implementam e aos testes que o verificam. Os endpoints estão **planejados** e podem ser ajustados durante a implementação; esta matriz é atualizada a cada grupo de tarefas, preenchendo as colunas de teste e status.

Referências: [requisitos](requisitos.md) · [casos de uso](casos-de-uso.md) · [modelagem](modelagem.md).

**Status:** Planejado · Parcial · Implementado · Opcional (modelado; implementação condicionada ao tempo).
